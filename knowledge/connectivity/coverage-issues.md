# Coverage Issue Resolution

## Coverage Definitions

### Good Coverage

RSRP above -90 dBm. RSRQ above -10 dB. SINR above 13 dB. Consistent signal without drops. Full speed data and reliable voice calls.

### Fair Coverage

RSRP between -90 and -105 dBm. RSRQ between -10 and -15 dB. SINR between 0 and 13 dB. Signal may vary. Data may be slower during peak hours. Voice calls generally work.

### Poor Coverage

RSRP below -105 dBm. RSRQ below -15 dB. SINR below 0 dB. Inconsistent signal. Frequent drops. Very slow data. Dropped calls likely.

### No Coverage

No detectable signal from any SmartConnect site. Device shows no service. No calls, texts, or data available.

## Common Coverage Issues

### Indoor Coverage Gaps

Low-band spectrum (600-700 MHz) provides best indoor penetration. Mid-band spectrum (1.7-2.5 GHz) provides moderate indoor coverage. High-band spectrum (mmWave) has poor indoor penetration. Building materials affect signal penetration significantly.

Resolution: Recommend Wi-Fi Calling for persistent indoor issues. Check if the building has a DAS or small cell. Suggest a signal booster for single-location improvement. Report coverage gap for network planning.

### Rural Coverage Gaps

Low population density makes rural coverage expensive. Low-band spectrum provides the widest rural coverage. Satellite backhaul may limit rural site capacity. Terrain affects coverage significantly.

Resolution: Verify the customer is within the coverage area. Check for known coverage gaps in the area. Suggest alternative carrier options if SmartConnect does not cover the area. Log the coverage gap for network expansion planning.

### Outdoor Dead Zones

Dead zones can occur between cell sites. Terrain features like hills and valleys cause dead zones. Dense urban environments with tall buildings cause signal shadowing. Construction zones may temporarily affect coverage.

Resolution: Verify the exact location of the dead zone. Check if it is a known coverage gap. Report the dead zone for network investigation. Suggest workaround routes or locations for consistent service.

## Coverage Investigation Process

### Step 1: Verify the Issue

Confirm the customer is within the SmartConnect coverage area. Check the coverage map for the reported location. Verify the customer's device supports the required frequency bands. Check for active network events in the area.

### Step 2: Gather Information

Collect the exact location of the coverage issue. Determine if the issue is indoors or outdoors. Note the time of day and duration of the issue. Ask about surrounding buildings or terrain features. Collect device model and operating system information.

### Step 3: Check Network Status

Review the site serving the area for any active events. Check site capacity and utilization. Verify site configuration and antenna alignment. Check for recent changes to the site.

### Step 4: Escalate if Needed

If the issue is confirmed and not resolved by standard troubleshooting, escalate to network engineering. Provide all collected information including location, device details, and network status. The network team will investigate and plan resolution.

## Coverage Improvement Solutions

### Small Cell Deployment

Low-power base stations for targeted coverage improvement. Ideal for filling specific coverage gaps. Faster to deploy than macro sites. Used in urban areas for capacity and coverage.

### DAS Installation

Distributed antenna systems for large buildings and venues. Provides consistent indoor coverage. Requires coordination with building management. Used for airports, stadiums, and convention centers.

### Macro Site Construction

New tower sites for wide area coverage. Longest deployment timeline. Highest cost but provides comprehensive coverage. Used for new coverage areas and major capacity upgrades.
