# Wi-Fi Calling Setup and Troubleshooting

## Overview

Wi-Fi Calling (VoWiFi) allows customers to make and receive calls over Wi-Fi networks when cellular coverage is poor or unavailable. This service uses the customer's existing phone number and plan minutes.

## Prerequisites

### Device Requirements

Device must support Wi-Fi Calling. Most modern smartphones support this feature. Check device specifications for compatibility. Device software must be up to date.

### Account Requirements

Customer must have an active postpaid account. Wi-Fi Calling must be enabled on the account. Customer must have a compatible device. SIM card must be provisioned for Wi-Fi Calling.

### Network Requirements

Device needs a working Wi-Fi internet connection. Minimum 1 Mbps for HD voice calls. Minimum 2 Mbps for video calls. Stable connection with low packet loss.

## Setup Procedures

### Android Devices

1. Open Settings on the device.
2. Navigate to Connections or Network & Internet.
3. Select Wi-Fi Calling.
4. Toggle Wi-Fi Calling to On.
5. Select calling preference: Wi-Fi Preferred or Cellular Preferred.
6. Complete any additional prompts.

### iOS Devices

1. Open Settings on the device.
2. Navigate to Phone or Cellular.
3. Select Wi-Fi Calling.
4. Toggle Wi-Fi Calling to On.
5. Confirm the emergency address when prompted.
6. Complete any additional prompts.

### Emergency Address Registration

Wi-Fi Calling requires a registered emergency address for E911 services. During setup, device will prompt for emergency address. Enter the primary address where the device will be used. Verify the address is correct. Update if address changes.

## Troubleshooting

### Wi-Fi Calling Not Available

Verify Wi-Fi Calling is enabled on the account. Check device compatibility. Ensure device software is up to date. Verify SIM card is active. Restart device and try again.

### Calls Not Connecting Over Wi-Fi

Check Wi-Fi internet connection is working. Verify Wi-Fi Calling is enabled in device settings. Check for firewall or port blocking on the Wi-Fi network. Required ports: UDP 500, UDP 4500, and IP protocol 50.

### Poor Call Quality on Wi-Fi

Check Wi-Fi signal strength. Minimum 2 bars recommended. Verify internet connection speed meets requirements. Reduce number of devices on the Wi-Fi network. Move closer to the Wi-Fi router. Consider using 5 GHz Wi-Fi band instead of 2.4 GHz.

### Calls Dropping When Switching Between Wi-Fi and Cellular

This is normal behavior during initial setup. Seamless handoff improves after a few calls. Ensure both Wi-Fi Calling and cellular are enabled. Check device settings for handover preferences. Update device software if issue persists.

## Known Limitations

Wi-Fi Calling does not support premium SMS services. Some carrier-specific features may not be available over Wi-Fi. Emergency calls may use the registered Wi-Fi Calling address rather than current location. Video calling over Wi-Fi may have lower quality than over cellular.
