# Technical Troubleshooting Guide

## Voice Call Issues

### Dropped Calls

If a customer reports dropped calls: check the customer's coverage area and signal strength, verify the serving cell site is operational, check for active network events in the area, review the customer's device and SIM status, and if the issue persists, escalate to network engineering with call logs and location data.

### One-Way Audio

If a customer reports hearing the other party but not being heard (or vice versa): verify both parties have active voice service, check for VoLTE registration issues, review the customer's APN settings, test with a different device if available, and if the issue persists, escalate with the call details and timestamps.

### Cannot Make Calls

If a customer cannot make calls: verify the line is active and not suspended, check for sufficient account balance or plan inclusions, verify the device has cellular service, check if VoLTE is enabled on the device, and test with a different device if available.

### Cannot Receive Calls

If a customer cannot receive calls: verify the line is active, check for call forwarding settings, verify the device is not in airplane mode, check for do-not-disturb settings, and verify the customer's number is correctly provisioned.

## Data Issues

### No Data Connection

If a customer has no data: verify mobile data is enabled in device settings, check that data is included in the customer's plan, verify APN settings are correct, check for data throttling due to plan limits, and run a speed test to confirm the issue.

### Slow Data

If a customer reports slow data: check the customer's signal strength and quality, verify the serving site is not congested, check for background app data usage, verify no VPN is active, and test at different times to rule out congestion.

### Intermittent Data

If a customer reports intermittent data: check for frequent handovers between cells, review signal quality variations, check for device power-saving settings that may affect connectivity, and verify the device software is up to date.

## Messaging Issues

### SMS Not Sending

If a customer cannot send SMS: verify the line has SMS capability, check for sufficient balance if prepaid, verify the device has cellular service, check the message center number in device settings, and test with a different device if available.

### MMS Not Sending

If a customer cannot send MMS: verify mobile data is working, check MMS APN settings, verify the messaging app has necessary permissions, check for sufficient storage space, and test with a different device if available.

### Delayed Messages

If messages are delayed: check for network congestion, verify the device has good signal, check for large message sizes that may cause delays, and verify the recipient's network is operational.

## Account and Billing Issues

### Incorrect Charges

If a customer disputes a charge: review the invoice details, check for any promotions or credits that should be applied, verify the plan pricing is correct, and apply credits or adjustments as appropriate per the billing dispute policy.

### Payment Issues

If a customer has payment issues: verify the payment method is valid, check for sufficient funds, review the payment history, and assist with alternative payment methods if needed.

### Plan Change Issues

If a customer has issues with a plan change: verify the change was processed correctly, check the effective date, verify any prorated charges are correct, and assist with any additional changes needed.
